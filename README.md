# Divine Divinity large fonts path
---
This is the original <b>Larian</b> font enlargement patch for <b>Divine Divinity</b>.</br>
The <b>font files</b> and the <b>.bat script</b> can be downloaded on Larian Studios forum:</br>
https://forums.larian.com/ubbthreads.php?ubb=showflat&Number=374873#Post374873</br>
</br>
The .bat script was rewritten in <b>Bash</b> to make it usable on Linux.</br>
No modifications whatsoever have been made to the original font files.</br>
</br>
The patch was tested on Steam version of the game that I ran on Debian 13.</br>
Your game's version and the corresponding file paths may vary so bare that in mind!</br>
</br>
---
## How to use:
* Download the original archive using the [https://www.dropbox.com/s/1xhxyb8j15e8m8y/DD_V2.0_font_enlargement_patch.zip?dl=1"](dropbox link)
* Unzip the patch archive in your game's <b>/fonts</b> directory
<sub><i>e.g. ~/.steam/debian-installation/steamapps/common/divine_divinity/fonts/</i></sub>
* Download the <b>DD_font_patch_Linux.sh</b> script <u>into the same directory</u>
<sub><i>if you can't figure how to download a file from Github you can copy the entire code and paste it into a new text file that you name accordingly</i></sub>
* Open the console inside the same directory
<sub><i>you can just open a terminal and enter the command: </i><code><b>cd ~/.steam/debian-installation/steamapps/common/divine_divinity/fonts/</b></code></sub>
* Make the script executable by running the command:
<code><b>chmod +x DD_font_patch_Linux.sh</b></code>
* Execute the script by running the command:
<code><b>./DD_font_patch_Linux.sh</b></code>
* The rest will be prompted in the terminal window
</br>
Enjoy your game, have fun!</br>
